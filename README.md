# Life Expectancy Predictor

## Introduction
Life Expectancy Predictor is a web application that uses artificial intelligence and a local calculation algorithm to estimate how long an individual may live based on their lifestyle and medical history. Users fill out a detailed health and lifestyle form, and the app provides a personalized prediction, risk factors, and health recommendations. All calculations are performed locally in the browser for privacy.

## Architecture Description
- **Frontend:** Built with HTML, CSS, and JAVASCRIPT, providing a modern, responsive user interface. All user interaction, data collection, and result display are handled in the browser.
- **AI & Algorithm:** The app uses a local algorithm (with an AI prompt/response simulation) to analyze user input and generate predictions, risk factors, and recommendations.
- **Styling:** The UI is styled for clarity and accessibility, using a clean, modern design.

## Utility & Value
This project provides users with:
- A private, educational tool to understand how lifestyle and medical history may impact life expectancy.
- Actionable health recommendations and risk factor analysis.
- An engaging, interactive experience with instant feedback.

## Full-Stack Development
- The application is fully functional end-to-end for local calculation and user interaction.
- All logic is implemented in the frontend; no backend or mainnet canister is required for the core experience.

## Code Quality
- The codebase is written in modern React with clear state management and modular functions.
- All major methods are commented for maintainability and clarity.

## Frontend
- The frontend is fully implemented and styled, providing a smooth user experience.
- All user input, calculation, and result display are handled in the browser.
